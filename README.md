GROUP10 HAJIME CAPSTONE PROJECT

PROJECT TITLE: Planet | Solar System Explorer
 1. Project Summary
Planet is a responsive web application that lets users search for any planet in our solar system and view its key facts. It is the capstone project of the Hajime cohort at TSAcademy, built by Group 10 with HTML, CSS and JavaScript.
The app uses the Fetch API to load planet information from a provided API, and shows each planet's name, image, type, description, gravity, mass, orbital period, temperature, moons, diameter and distance from the Sun. A comparison table shows data for all the planets.

It’s Features
- Search by planet name (full or partial, any capitalisation)
- "No results found!" state when a search does not match a planet
- Light and dark mode, with the choice remembered between visits
- Responsive layout for desktop, tablet and mobile
- Semantic HTML and accessible labels
Built with: HTML, CSS, JavaScript (Fetch API), Google Fonts

4. Running the Project Locally
You can view the project on your own computer without publishing it online.

Option A: Download the Project
- Open the Group 10 GitHub repository.
- Click the green Code button.
- Select Download ZIP.
- Once the download finishes, open the ZIP file and extract its contents into a folder.
- Open the extracted GROUP10-PROJECT folder.
- Find and open index.html in your web browser, such as Chrome or Microsoft Edge.

The website should open locally. An internet connection is needed for the application to retrieve planetary data from its external API.

Option B: Run the Project Using Visual Studio Code
- Install Visual Studio Code if it is not already installed.
- Install Git if you intend to clone the repository.
- Open Visual Studio Code and choose Clone Git Repository, or open a terminal and run:
- git clone https://github.com/oyin-ad/GROUP10-PROJECT.git
- Open the cloned GROUP10-PROJECT folder in Visual Studio Code.
- Find index.html in the file explorer.
- If you have the Live Server extension installed, right-click index.html and select Open with Live Server.
- Your browser will open the project locally. Keep an internet connection available so the Fetch API can retrieve the planetary data.

Troubleshooting: If the page opens but the planet information does not load, check your internet connection and the browser console for API or JavaScript errors. Running the page with Live Server can also help avoid issues associated with opening an HTML file directly.
