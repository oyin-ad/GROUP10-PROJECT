# GROUP10-PROJECT
GROUP10 HAJIME CAPSTONE PROJECT

PROJECT TITLE: Planet | Solar System Explorer
 1. Project Summary
Planet is a responsive web application that lets users search for any planet in our solar system and view its key facts. It is the capstone project of the Hajime cohort at TSAcademy, built by Group 10 with HTML, CSS and JavaScript.
The app uses the Fetch API to load planet information from a provided API, and shows each planet's name, image, type, description, gravity, mass, orbital period, te⁵mperature, moons, diameter and distance from the Sun. A comparison table shows data for all the planets.
It’s Features
- Search by planet name (full or partial, any capitalisation)
- "No results found!" state when a search does not match a planet
- Light and dark mode, with the choice remembered between visits
- Responsive layout for desktop, tablet and mobile
- Semantic HTML and accessible labels
Built with: HTML, CSS, JavaScript (Fetch API), Google Fonts

4. Run the Project Locally
Option A: download the files
1. Click the green Code button on this repository and choose Download ZIP.
2. Unzip the folder.
3. Open `index.html` in a web browser.
Option B: clone with Git
-	```bash
-	git clone
-	https://github.com/oyin-ad/GROUP10-PROJECT.git cd GROUP10-PROJECT
-	```
Then open `index.html` in a browser.
Notes
- You need an internet connection. The planet data, planet images and fonts load online.
- The project has no dependencies, so there is nothing to install.
